## 🚀 ¿Qué es AI SmartSend?

AI SmartSend es una aplicación de escritorio para **Windows** que automatiza el envío de mensajes de WhatsApp a múltiples contactos, con personalización individual para cada persona y programación flexible de envíos.

Desarrollado por **[Cual & Cuanti — AI Smart Marketing](https://darkgrey-ibis-936997.hostingersite.com/)**, como parte de su portafolio de soluciones de automatización con Inteligencia Artificial.

## ✨ Características principales

| Característica | Descripción |
|---|---|
| 🎯 **Personalización** | Variables `{nombre}`, `{empresa}`, `{fecha}` y cualquier columna de tu Excel |

| 🔁 **Repetición** | Diario, semanal, quincenal, mensual o cada X días |

| 🔐 **Seguridad** | Versión Pro vinculada al equipo autorizado |

## 💬 Variables de personalización

Usa estas variables en tu mensaje y se reemplazarán automáticamente:

```
{nombre}    → Nombre del contacto
{fecha}     → Fecha actual (ej: 28/03/2026)
{hora}      → Hora actual (ej: 09:30)
{dia}       → Día de la semana (ej: Sábado)
{mes}       → Mes actual (ej: Marzo)
{empresa}   → Cualquier columna de tu Excel
```

**Ejemplo de mensaje:**
```
🎉 ¡Hola {nombre}! Hoy es {dia} {fecha}.
Te escribimos desde {empresa} con una novedad especial.
¡Contáctanos! 🚀
```
